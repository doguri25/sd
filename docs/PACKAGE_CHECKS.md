# GitHub 패키지 확인 기록

## 실행 확인

로컬 HTTP 클라이언트와 Chromium 브라우저를 사용한 기본 검사 23항목 중 22항목을 통과했습니다. 나머지 1항목은 아래 모바일 가장자리 표시 주의 사항입니다. 전체 게임 기능을 새로 전수 검사한 기록은 아닙니다.

확인한 내용:

- 루트 `/`와 프로젝트 하위 `/samguk-dodgeball/`에서 `index.html`과 상대 경로의 문서·지도 데이터·스크린샷이 HTTP로 제공되는지 확인했습니다.
- 원본 HTML을 브라우저에 로드하여 메인, 경기 설정, 원정 경기, 일시정지와 재개, UI에서 점령전 시작을 확인했습니다.
- 런타임의 17개 진영·99명 정식 장수·53개 구장·51개 점령 거점을 확인했습니다.
- 점령전 기록을 실제 JSON 파일로 내보내고 다시 불러와 도시 소유권이 유지되는지 확인했습니다.
- 확인한 데스크톱·모바일 기본 흐름에서 JavaScript `pageerror`는 없었습니다. 게임 실행용 외부 HTTP 리소스 요청도 관찰되지 않았습니다.
- 모바일 가로 화면 에뮬레이션에서 터치로 설정 열기와 경기 시작을 확인했습니다.

세부 결과는 [smoke-results.json](smoke-results.json)에 있습니다.

## 모바일 표시 주의 사항 — 원본 유지

844×390 모바일 에뮬레이션의 직접 HTML 로드 환경에서 `innerHeight`가 397, 시각 뷰포트 높이가 390으로 보고되어 게임 영역이 세로로 약 7px 크게 계산되는 현상을 관찰했습니다. 위아래 가장자리 약 3.5px씩의 차이이며, 주요 버튼의 터치와 경기 시작은 작동했습니다. 원본 v9를 그대로 패키징하므로 화면 코드를 수정하지 않았습니다. 실제 배포 주소와 실제 기기에서의 표시 상태는 별도 확인이 필요합니다.

## 확인하지 못한 범위

검사 환경 정책으로 Chromium의 로컬 HTTP 주소 탐색이 차단되었습니다. 따라서 HTTP 경로는 Python 로컬 HTTP 클라이언트로 검사했고, 브라우저 기능은 **변경하지 않은 HTML 문자열을 직접 로드**하여 확인했습니다. 두 검사를 실제 GitHub Pages URL 방문 검사로 표현하지 않습니다.

GitHub 계정에 업로드하거나 실제 Pages 배포를 실행하지 않았습니다. 실제 휴대폰 하드웨어와 배포된 주소에서의 `localStorage` 지속성도 확인하지 않았습니다. 기존 기록의 파일 내보내기·불러오기는 확인했습니다.

## 패키지 자체 검사

`python tools/check_package.py`로 필수 파일, 원본·패키지 해시, 문서의 로컬 링크, JSON 형식, 폰트 파일 미포함, 외부 실행 리소스 태그 미사용, Node.js 인라인 스크립트 문법을 확인할 수 있습니다. 패키징 때 이 검사를 실행합니다.

이 문서는 기존 v9 개발 단계의 검증 건수를 이번 배포 패키지의 검사 수로 다시 계산하지 않았습니다.
