# 삼국지 피구대전 : 천하도 v9 — 게임 사용 안내

## 1. 실행
index.html 파일을 PC 웹 브라우저에서 여세요.
이미지·음원·외부 라이브러리 파일을 따로 설치할 필요가 없습니다.
역사·지리 참고 자료 링크를 열 때에만 인터넷이 필요합니다.
모바일 화면은 가로 방향을 기준으로 만들었습니다.

## 2. 시작과 조작
왼쪽에서 진영 선택 → 출전 장수 3명 선택 → 경기 설정 → 점령전.
이동: 방향키 또는 WASD / 던지기: J / 잡기: K / 회피: L
특징 기술: E / 필살기: R / 교대·패스: Q
장수 바로 선택: 1·2·3 / 일시정지: P / 전체 화면: F
화면 조이스틱·버튼도 사용할 수 있습니다.

## 3. 지도
점령 거점 34곳을 51곳으로 늘렸습니다. 17개 진영이 새 게임에서 3곳씩 무작위로 받습니다.
별도 전장인 적벽·오장원을 포함하면 일반 경기 구장은 53곳입니다.
내 도시를 누른 뒤 연결된 상대 도시를 선택하여 공격하세요.
선택한 도시의 이웃을 강조하며, 연결·지형 버튼으로 지도 표시를 바꿀 수 있습니다.
확대·축소, 확대 후 드래그 이동, 전체 보기 기능이 있습니다.
왕관 표시는 지원병이 배정되는 대도시입니다.
지도는 새로 그린 게임용 도식입니다. 다른 게임의 지도 이미지나 글꼴을 포함하지 않습니다.
실제 역사적 국경·행정 경계·하천 유로·도로망을 그대로 복원한 지도는 아닙니다.

새로 추가한 17개 거점:
평원, 남피, 북해, 진류, 낭야, 초, 완, 신야, 무릉, 영릉, 계양, 강하, 시상, 여강, 파군, 자동, 남해.

## 4. 점령전 기본 규칙
살아 있는 모든 진영에 차례가 한 번씩 돌아가는 기간을 '전체턴'이라 합니다.
새 전체턴마다 살아 있는 진영의 순서를 무작위로 정합니다.
자기 차례에는 연결된 상대 지역에 한 번 공격하거나 차례를 넘길 수 있습니다.
한 번 방어한 진영은 그 전체턴 동안 다른 지역까지 다시 공격받지 않습니다.
이미 방어한 진영도 자기 차례의 공격은 할 수 있습니다.

공격 성공: 목표 도시만 공격 진영 소유가 됩니다.
공격 실패: 공격팀·수비팀 모두 기존 도시를 그대로 유지합니다. 역점령은 없습니다.
마지막 도시 함락: 해당 세력의 멸망 메시지를 표시하고 지도 기록에 남깁니다.
모든 도시 획득 시 천하 통일, 내 마지막 도시 상실 시 점령전 종료입니다.
공격팀은 오른쪽 AWAY, 수비팀은 왼쪽 HOME에서 목표 도시의 구장으로 경기합니다.
컴퓨터끼리의 경기는 출전 명단·체력·병종·지역 특성·대도시 지원과 무작위성을 반영해 자동 정산합니다.

## 5. 장수별 체력 유지와 휴식 — 점령전 전용
공격이나 수비가 끝나면 양쪽 출전 장수의 실제 남은 체력을 각각 기록합니다.
쉬움: 최소 80% / 보통: 최소 75% / 어려움: 최소 70%.
최저선보다 높은 체력은 그대로 둡니다. 아웃된 장수도 최저선으로 정비됩니다.
소수점·정수 체력 표시 때문에 1HP 미만의 표시 차이가 생길 수 있습니다.
선발 선택 화면에 다음 경기 시작 체력 비율이 표시됩니다.

예: 보통 난이도에서 20%, 82%, 100%가 남았다면 정비 후 75%, 82%, 100%가 됩니다.
제1턴에 출전했다면 제2턴 시작 때 정비한 체력으로 남습니다.
그 장수가 제2턴 전체 동안 공격·수비에 한 번도 출전하지 않았다면 제3턴 시작 때 100%가 됩니다.
한 턴 중 한 차례만 쉬거나, 그 턴에 수비로 출전하면 '전체턴 휴식'이 아닙니다.
군공은 정비 후가 아니라 경기 종료 시점의 실제 남은 체력을 기준으로 계산합니다.
일반 경기·제패전의 기존 경기별 회복 방식은 유지했습니다.

## 6. 병종 — 99명의 정식 장수에게 각각 1종 배정
보병: 받는 피해 12% 감소.
기병: 이동 속도 15% 증가.
창병: 모든 투구 피해 12% 증가.
궁병: 특징 기술 피해 20% 증가.
방패병: 최대 체력 18% 증가.
문관: 필살기 피해 18% 증가.
군주: 균형형. 출전 명단에 있으면 아군 핵심 능력 3% 증가.

군주의 아군 보너스는 최대 체력·이동·투구 피해·기 충전·방어 계수에 적용됩니다.
군주를 여러 명 출전시켜도 중복되지 않습니다. 출전 시 적용한 보너스는 그 경기 동안 유지됩니다.
장수별 병종은 역사·연의의 이미지와 게임 균형을 참고한 배정으로 실제 병과 편제의 복원이 아닙니다.
전체 명단은 'data/officer-classes-v9.txt'에서 확인할 수 있습니다.

## 7. 지역 특성
평야 / 북방·서량 변경 / 구릉·고원 / 산악·협곡 / 농경 분지 / 하천·수향 /
남부 산림 / 해안·항구 / 도성·중심 시가지의 9종입니다.
지역별로 일곱 병종의 주특기 능력에 +5% 또는 -5% 보정이 적용됩니다.
기병은 이동, 창병은 투구 피해, 궁병은 특징 기술, 방패병은 최대 체력,
문관은 필살기, 보병은 방어 효율, 군주는 균형 능력에 보정을 받습니다.
방어 +5%는 들어오는 피해를 1.05로 나누고, 방어 -5%는 0.95로 나누는 방식입니다.
기본 병종·지역·군주·아이템 보너스는 해당 계수끼리 곱해집니다.
예: 기병의 지역 이동 +5%라면 기본 이동 속도 ×1.15×1.05가 됩니다(다른 보너스 제외).
양 팀 모두 목표 도시의 같은 지형 규칙을 적용받습니다.
지도에서 도시를 누르면 지역 특성과 일곱 병종의 유불리가 표시됩니다.

지형·도읍 분류에는 역사·지리 자료를 참고했습니다.
그러나 ±5%와 병종 배정, 대도시 지원병 인원은 게임 균형을 위한 규칙이며 실제 전투 통계가 아닙니다.
현대 지형 개요를 포함한 자료이므로 특정 도시의 3세기 식생·기후·인구를 정밀 복원한 것은 아닙니다.
도시별 상세표와 원자료 링크는 별도 문서 및 게임 안 '병종·규칙' 도감에 있습니다.

## 8. 대도시 지원병 — 점령전 수비팀 전용
낙양, 장안, 성도, 건업, 업성, 허도에 적용됩니다.
한·삼국 시대를 아우르는 도읍·주요 정치 거점이라는 성격을 참고한 게임용 선정이며,
어느 한 해의 인구 순위나 모든 지역의 도시 규모를 확정한 목록은 아닙니다.

경기 시작 때 창병·궁병·방패병 중 무작위로 총 1~2명의 지원병을 배정합니다.
수비팀 장수가 아웃되면 빈 자리에 지원병이 들어옵니다. 경기장에는 한 팀 최대 3명만 활성 상태로 남습니다.
지원병도 체력 0이 되면 아웃됩니다. 배정된 1~2명을 모두 사용하면 더 나오지 않습니다.
원래 장수가 모두 아웃되어도 지원병이 남아 있다면 경기가 계속됩니다.
지원병은 일시 출전 유닛으로 영구 장수 명단에 추가되지 않으며 군공 체력 점수에도 포함되지 않습니다.
지원병의 종류·인원은 저장 후 재개나 경기 재시작으로 다시 뽑히지 않습니다.

## 9. 상점과 기존 기능
군공 상점, 1~2경기용 아이템, 장수 기술, 공 회전, 벽 반사 후 무해한 데드볼,
필살기 잡기 충격, 발밑 흙먼지, 홈·어웨이, 다양한 오프볼 움직임을 유지했습니다.
점령전 군공 정산은 원래 출전 장수 세 명의 실제 남은 체력으로 계산합니다.
지원병 체력과 전투 후 자동 정비 체력으로 점수가 늘지 않습니다.

## 10. 저장과 v8 기록
브라우저 저장을 지원하며, 제한된 환경에서는 화면에 '파일 저장 필요'가 표시됩니다.
지도 '기록 저장' 또는 메인의 기록 메뉴에서 JSON 파일을 내보내 보관하세요.
내보내기에는 군공·아이템·도시 소유권·턴·장수별 체력·미완료 전투가 포함됩니다.
미완료 전투는 경기 시작 시점의 체력과 지원병 배정으로 다시 시작합니다.
재시작·이어하기로 이미 사용한 아이템 횟수를 다시 차감하지 않습니다.

v8의 내보낸 JSON 기록을 불러올 수 있습니다.
기존 34개 거점 소유권을 유지하고, 새 17개 거점은 당시 살아 있는 진영에 배정합니다.
v8에 없던 장수별 체력 기록은 100%로 시작합니다.
새 게임은 처음부터 51개를 진영당 3개씩 배정합니다.
파일명·브라우저·저장 권한이 달라지면 자동 저장 기록이 보이지 않을 수 있으므로
중요한 진행 상황은 JSON 파일로 따로 보관하세요.
